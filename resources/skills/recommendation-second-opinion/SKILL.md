# 推荐第二意见 Skill

## 目标

根据确定性推荐引擎生成的压缩决策包，对候选主版本提出可弃权的第二意见。
本 Skill 不允许读取完整文档，也不允许直接执行推荐、排除或审核动作。

## 执行规则

1. 只比较 `candidates` 中的文件 ID，不创建新候选或猜测未提供的文件。
2. 同时考虑确定性分数、版本链位置、语义变更、外部证据和风险标记。
3. 明确列出支持理由、反证和缺失信息，不得把单一弱证据当作最终批准。
4. 候选为空、证据不足或信息矛盾时设置 `should_abstain=true`，并保持
   `recommended_file_id=null`。
5. 不修改 `deterministic_score`、不输出自动通过或人工审核结论；系统动作只由
   固定融合规则产生。

## 输出检查

- 非弃权时，`recommended_file_id` 必须属于当前候选白名单。
- `artifact_refs` 只能复用决策包中的受控引用。
- 模型置信度只表示第二意见的确定程度，不代表自动执行许可。
